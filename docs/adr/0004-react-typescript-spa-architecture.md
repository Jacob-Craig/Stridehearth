# 0004. React 19 and Kotlin-Aligned TypeScript SPA Architecture

Replace the server-rendered Thymeleaf and Bootstrap 5 frontend with a single-page application (SPA) built using Vite, React 19, and strict Kotlin-aligned TypeScript (`frontend/`), backed by Spring Boot JSON REST APIs (`/api/**`) and packaged into the executable Spring Boot JAR for single-unit production deployment.

## Considered Options

- **Application Boundary & Rendering Model**: Selected a decoupled client-side React 19 SPA (`Vite` + `TanStack Router` + `TanStack Query`) communicating with Spring Boot exclusively over JSON REST endpoints. Rejected Next.js / SSR frameworks (which introduce a separate Node.js production server runtime and duplicate routing/auth concerns) and Kotlin/JS React wrappers (which sacrifice native TypeScript ecosystem ergonomics, Tailwind/shadcn tooling, and Vite HMR speed).
- **End-to-End API Contract & Code Generation**: Selected `springdoc-openapi` (generating an OpenAPI 3.1 specification from Kotlin `@RestController` and DTO signatures during the Gradle build) paired with `@hey-api/openapi-ts` to generate strictly-typed TypeScript interfaces, Zod validation schemas, and TanStack Query hooks. Rejected manual TypeScript DTO maintenance (prone to drift during a large port) and reflection-only type generators that omit runtime schema validation and endpoint client bindings.
- **TypeScript Paradigm Alignment with Kotlin**: Selected strict compiler flags (`strict: true`, `noUncheckedIndexedAccess: true`, `exactOptionalPropertyTypes: true`), immutable data transforms, discriminated union state and error modeling (`kind` discriminator) with `ts-pattern` exhaustive matching (mirroring Kotlin `sealed interface` + `when`), and TanStack Form backed by generated Zod schemas.
- **Authentication & Routing Security**: Selected stateful Spring Security `HttpSession` cookies with `CookieCsrfTokenRepository.withHttpOnlyFalse()` (SPA CSRF handling) and dedicated `/api/auth/{login,register,logout,me}` JSON endpoints, paired with a Spring SPA fallback forwarder to `index.html` and TanStack Router `beforeLoad` authentication guards. Rejected stateless JWTs to preserve immediate server-side session revocation and avoid token storage vulnerabilities.
- **High-Frequency Telemetry & Spatial Visualization**: Selected `maplibre-gl` (WebGL 2D/3D vector maps) and `uplot` (HTML5 Canvas time-series charts) wrapped in React 19 components that synchronize 60–120fps cursor scrubbing via a ref/pub-sub channel outside React's render loop, while keeping discrete selections (such as **Best Effort** window highlights) in React state. Rejected SVG-based React chart libraries (such as Recharts or Visx) due to DOM reflow bottlenecks when rendering and scrubbing across 9 synchronized 1Hz sensor streams.

## Consequences

- **Pure JSON REST Backend & Standardized Error Envelopes**: All Thymeleaf templates (`src/main/resources/templates/**`), MVC view controllers, preformatted view strings on DTOs, and legacy `/runs/**` redirects are replaced by canonical `/api/**` endpoints returning `PagedResponseDTO<T>` for paginated collections and a discriminated `ApiErrorResponse` (`kind`, `message`, `fieldErrors`) via `@RestControllerAdvice`.
- **Zero-Copy Telemetry Passthrough with Typed Schema**: `GET /api/activities/{id}/telemetry` continues streaming raw PostgreSQL-constructed JSON from `ActivityDetailsRepository.findTelemetryJson` for zero-deserialization overhead, while declaring an explicit OpenAPI `@Schema` response contract so the TypeScript client receives full static and runtime types for **Activity Details** and **Best Efforts**.
- **Peak Perceived and Runtime Performance**: Route transitions use TanStack Router intent preloading (`defaultPreload: 'intent'`) integrated with TanStack Query caching and the browser View Transitions API. Below-the-fold chart stacks and dense management tables apply CSS `content-visibility: auto` with `contain-intrinsic-size`, `font-variant-numeric: tabular-nums` for metric legibility, and native `color-scheme: light dark` theming synced across Tailwind CSS v4, MapLibre GL styles, and uPlot canvas palettes.
- **Unified Gradle, Pre-Push, and CI Verification**: The Gradle build orchestrates frontend dependency installation, OpenAPI contract freshness, TypeScript typechecking (`tsc --noEmit`), Biome linting/formatting, Vitest unit/component suites, and static bundle packaging into `bootJar`, extending the existing `.githooks/pre-push` and GitHub Actions CI guardrails established in ADR-0002. `processResources` copies `frontend/dist/**` into `static/`, so the SPA ships in `BOOT-INF/classes/static` and is also on the test and `bootRun` classpath.
- **Committed OpenAPI Snapshot as the Contract**: `frontend/openapi.json` is committed and is the only input to `npm run codegen` (`frontend/src/api/generated` is committed too), so the frontend builds without a running backend. Freshness is enforced in two cheap, deterministic halves: `OpenApiContractTest` fails when the live `/v3/api-docs` differs (order-insensitive JSON comparison) from the snapshot, and `npm run codegen:check` (Gradle `frontendCodegenCheck`) regenerates into a temp directory and fails when `src/api/generated` differs from it. An intentional API change is accepted with `./gradlew test -PupdateOpenApiSnapshot --tests '*OpenApiContractTest'` followed by `npm run codegen`, committing both.
